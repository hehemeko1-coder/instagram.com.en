Before you sign in

Check the domain carefully. A page can copy a brand's appearance without belonging to that brand.

  • Verify the website address before entering credentials.
  • Use a password manager; it can help detect an unfamiliar domain.
  • Never reuse passwords, and enable multi-factor authentication.

Use a clearly fictional username and a made-up password for this exercise. The password stays in your browser and is never transmitted or saved.
